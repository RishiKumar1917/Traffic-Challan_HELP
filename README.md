# Traffic-Challan HELP ⚖️🚘

**Traffic-Challan HELP** is a mobile-first, citizen-empowerment web application designed to help drivers and vehicle owners in India understand their legal rights when stopped by traffic police or when facing unfair/defective e-challans.

---

## 🌟 Key Features

1. **🚨 Instant "Police Stop" Emergency Proof Mode**:
   - One-tap high-contrast display mode optimized for mobile screens.
   - Shows verbatim statutory provisions and MoRTH circular text directly to traffic inspecting officers.

2. **📜 Statutory Rights & MoRTH Circular Database**:
   - **DigiLocker & mParivahan Validity**: Section 4 of IT Act 2000 & MoRTH Circular RT-11036/64/2017-MV (Digital DL, RC, Insurance, and PUC treated at par with physical originals).
   - **15-Day Grace Period**: CMVR 1989 Rule 139 for document production before compounding.
   - **Officer Rank Authority**: Compounding power limits for constables vs Sub-Inspectors (Section 200 MV Act).
   - **Key Removal & Tire Deflation Prohibition**: Directives prohibiting illegal ignition key snatching or vehicle damage.

3. **💰 Interactive Offence & Fine Finder**:
   - Search by offence (e.g. Helmet, Seatbelt, PUC, Overspeeding, Drunk Driving, Red Light Jump).
   - Shows exact MV Act sections, standard fines, authorized compounding ranks, and statutory defenses.

4. **🏛️ Landmark High Court Precedents**:
   - Rulings on speed camera calibration certificates, speed limit signage requirements, and police conduct manuals.

5. **✍️ Automated E-Challan Dispute Letter Generator**:
   - Fill in vehicle details, e-challan number, and reason for dispute to instantly generate a formal representation letter for Virtual Courts / Appellate Traffic Police Officers.

## 🚀 How to Run Locally

Since this application is built with standard modern HTML5, CSS3, and JavaScript, you can run it directly:

1. Open `index.html` in any web browser (Google Chrome, Mozilla Firefox, Safari, Microsoft Edge).
2. Alternatively, serve via a local HTTP server:
   ```bash
   npx -y http-server ./ -p 8080
   ```
3. Open `http://localhost:8080` in your mobile browser or desktop browser.
